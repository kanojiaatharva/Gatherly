# Architecture

## High-level flow
React client -> Spring Boot REST API -> domain services -> MySQL
                                  -> AI provider adapter -> model API

## Design principles
- Keep AI integration behind an `AiPlanningProvider` interface.
- Treat model output as untrusted input: parse, validate, normalize, then persist.
- Use deterministic services for arithmetic, permissions, date calculations, and state transitions.
- Keep prompts versioned under source control.
- Use transactions for related event/budget/task changes.
- Use database migrations (Flyway recommended).
- Return DTOs rather than exposing JPA entities directly.

## AI safety and reliability
- Validate schema, currency, numeric ranges, dates, and references.
- Never execute arbitrary code or SQL generated by the model.
- Tools should be narrow, typed, and authorized by the backend.
- Ask for confirmation before external side effects such as sending invitations or making bookings.
- Explain assumptions and distinguish estimates from verified data.
